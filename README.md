# 🩺 Multiple Disease Prediction System

An end-to-end Machine Learning application that predicts the likelihood of multiple diseases using patient clinical data. The project integrates trained Machine Learning models with an interactive Streamlit web application, enabling users to perform real-time predictions for:

- 🩺 Chronic Kidney Disease
- 🫀 Liver Disease
- 🧠 Parkinson's Disease

---

## 📌 Project Overview

Early disease detection plays a vital role in improving patient outcomes. This project leverages Machine Learning algorithms trained on publicly available healthcare datasets to assist in predicting multiple diseases based on patient health parameters.

The application provides an intuitive interface where users can enter medical information and instantly receive prediction results.

> **Disclaimer:** This application is intended for educational purposes only and should not be used as a substitute for professional medical diagnosis.

# 🏥 Diseases Covered

## 🩺 Chronic Kidney Disease

Predicts the likelihood of Chronic Kidney Disease using clinical laboratory parameters such as:

- Blood Pressure
- Specific Gravity
- Albumin
- Sugar
- Blood Glucose Random
- Serum Creatinine
- Hemoglobin
- Packed Cell Volume
- White Blood Cell Count
- Red Blood Cell Count
- and more...

---

## 🫀 Liver Disease

Predicts Liver Disease using patient health indicators including:

- Age
- Gender
- Total Bilirubin
- Direct Bilirubin
- Alkaline Phosphotase
- Alanine Aminotransferase
- Aspartate Aminotransferase
- Total Proteins
- Albumin
- Albumin & Globulin Ratio

---

## 🧠 Parkinson's Disease

Predicts Parkinson's Disease using voice measurement features including:

- Fundamental Frequency
- Jitter
- Shimmer
- Noise-to-Harmonics Ratio
- Harmonics-to-Noise Ratio
- RPDE
- DFA
- Spread
- PPE
- and other speech characteristics
